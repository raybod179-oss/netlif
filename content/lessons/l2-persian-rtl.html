راست‌به‌چپ کردن سایت

کدhtml
<!DOCTYPE html>
<html lang="{{ str_replace('_', '-', app()->getLocale()) }}"
      dir="{{ app()->getLocale() === 'fa' ? 'rtl' : 'ltr' }}">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <link rel="stylesheet" href="{{ asset('css/app.css') }}">
</head>
  • Tailwind: به‌جای ml-4 / pr-2 از ویژگی‌های منطقی استفاده کن: ms-4 (شروع)، me-4 (پایان)، ps-2، pe-2، text-start تا هم در RTL هم LTR درست باشد. برای حالت‌های خاص rtl: و ltr:.
  • Bootstrap 5: نسخه‌ی RTL آن (bootstrap.rtl.min.css) را به‌جای نسخه‌ی عادی لود کن.
  • آیکون‌های جهت‌دار: فلش‌ها و «بعدی/قبلی» را در RTL برعکس کن.

فونت فارسی؛ بدون وابستگی به سرویس خارجی

Google Fonts در ایران گاهی کند یا قطع است و سایت را کند می‌کند. فونت را خودت روی سرور میزبانی کن (مثلاً Vazirmatn که رایگان و متن‌باز است).

کدcss
@font-face {
    font-family: 'Vazirmatn';
    src: url('/fonts/Vazirmatn-Regular.woff2') format('woff2');
    font-weight: 400;
    font-display: swap;      /* متن تا لود فونت نامرئی نماند */
}
@font-face {
    font-family: 'Vazirmatn';
    src: url('/fonts/Vazirmatn-Bold.woff2') format('woff2');
    font-weight: 700;
    font-display: swap;
}
body { font-family: 'Vazirmatn', Tahoma, system-ui, sans-serif; }
عدد و متن مختلط

ایمیل، آدرس سایت و شماره تلفن در متن فارسی گاهی به‌هم می‌ریزند. آن‌ها را داخل <bdi dir="ltr">...</bdi> یا یک المنت با dir="ltr" بگذار.

تاریخ شمسی

دیتابیس همیشه تاریخ میلادی ذخیره می‌کند (و باید همین‌طور باشد)؛ فقط هنگام «نمایش» به شمسی تبدیل می‌کنیم و هنگام «دریافت از کاربر» برعکس.

کدbash
composer require morilog/jalali
کدphp
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Casts\Attribute;
use Illuminate\Database\Eloquent\Model;
use Morilog\Jalali\Jalalian;

class Order extends Model
{
    // $order->created_at_jalali  ←  «۱۴۰۵/۰۲/۱۵»
    protected function createdAtJalali(): Attribute
    {
        return Attribute::make(
            get: fn () => Jalalian::fromCarbon($this->created_at)->format('Y/m/d H:i'),
        );
    }
}

// تبدیل ورودی کاربر (شمسی) به Carbon برای ذخیره:
// $date = Jalalian::fromFormat('Y/m/d', '1405/02/15')->toCarbon();
منطقه‌ی زمانی

اگر سایتت فقط برای ایران است، 'timezone' => 'Asia/Tehran' را در config/app.php بگذار تا now() و زمان‌بندها به وقت تهران باشند. در سایت‌های چندکشوری بهتر است UTC نگه داری و هنگام نمایش تبدیل کنی.

ارقام و نرمال‌سازی ورودی فارسی

کاربران ایرانی گاهی عدد را با ارقام فارسی (۰۹۱۲...) یا عربی می‌نویسند و گاهی «ی» و «ک» عربی (ي، ك) تایپ می‌شود. اگر نرمال نکنی، جست‌وجو و ورود با شماره‌ی موبایل خراب می‌شود. یک helper بنویس و در prepareForValidation استفاده کن.

کدphp
<?php

// app/helpers.php  (در composer.json بخش autoload.files اضافه شود)

if (! function_exists('en_digits')) {
    function en_digits(string $value): string
    {
        return strtr($value, [
            '۰' => '0', '۱' => '1', '۲' => '2', '۳' => '3', '۴' => '4',
            '۵' => '5', '۶' => '6', '۷' => '7', '۸' => '8', '۹' => '9',
            '٠' => '0', '١' => '1', '٢' => '2', '٣' => '3', '٤' => '4',
            '٥' => '5', '٦' => '6', '٧' => '7', '٨' => '8', '٩' => '9',
        ]);
    }
}

if (! function_exists('fa_digits')) {
    function fa_digits(string|int $value): string
    {
        return strtr((string) $value, [
            '0' => '۰', '1' => '۱', '2' => '۲', '3' => '۳', '4' => '۴',
            '5' => '۵', '6' => '۶', '7' => '۷', '8' => '۸', '9' => '۹',
        ]);
    }
}

if (! function_exists('fa_normalize')) {
    function fa_normalize(string $value): string
    {
        return trim(str_replace(['ي', 'ك'], ['ی', 'ک'], $value));
    }
}
کدjson
{
    "autoload": {
        "psr-4": { "App\\": "app/" },
        "files": ["app/helpers.php"]
    }
}
کدphp
<?php

namespace App\Http\Requests;

use Illuminate\Foundation\Http\FormRequest;

class RegisterRequest extends FormRequest
{
    protected function prepareForValidation(): void
    {
        $this->merge([
            'phone' => en_digits((string) $this->input('phone')),
            'name'  => fa_normalize((string) $this->input('name')),
        ]);
    }

    public function rules(): array
    {
        return [
            'name'  => ['required', 'string', 'max:100'],
            'phone' => ['required', 'regex:/^09\d{9}$/', 'unique:users,phone'],
        ];
    }
}

بعد از تغییر composer.json یک‌بار composer dump-autoload بزن.

اسلاگ و جست‌وجوی فارسی

آدرس‌هایی مثل /posts/آموزش-لاراول هم قانونی‌اند و برای سئوی فارسی خوب‌اند. تابع زیر حروف و ارقام (فارسی و لاتین) را نگه می‌دارد و بقیه را به خط تیره تبدیل می‌کند و نیم‌فاصله را هم درست مدیریت می‌کند.

کدphp
<?php

function fa_slug(string $title): string
{
    $title = str_replace(["\u{200c}", 'ي', 'ك'], [' ', 'ی', 'ک'], $title);   // نیم‌فاصله ← فاصله
    $title = mb_strtolower($title);
    $title = preg_replace('/[^\p{L}\p{N}]+/u', '-', $title);

    return trim($title, '-');
}

echo fa_slug('آموزش Laravel برای مبتدی‌ها!');   // آموزش-laravel-برای-مبتدی-ها
خروجیخروجی
آموزش-laravel-برای-مبتدی-ها
ستون یکتا

اسلاگ را در جدول با unique تعریف کن و اگر تکراری بود پسوند -2 اضافه کن.

اشتباه‌های رایج

  1. فراموش‌کردن dir="rtl" روی html و رفتن همه‌چیز به‌هم.
  2. استفاده از ml-/pr- به‌جای ms-/pe- و خراب‌شدن حالت LTR.
  3. ذخیره‌ی تاریخ شمسی در دیتابیس به‌جای میلادی.
  4. نرمال‌نکردن ارقام در ورودی (شماره‌ی موبایل ورود نمی‌خورد).
  5. اتکا به Google Fonts.
  6. استفاده از strlen و substr روی فارسی؛ از mb_ استفاده کن.

تمرین‌ها

تمرین ۱
  1. قالب اصلی (layout) سایت را RTL کن و فونت Vazirmatn را محلی لود کن.
  2. ببین کدام قسمت‌های چیدمان به‌خاطر margin-left/right اشتباه شده‌اند و درستشان کن.
تمرین ۲
  1. Accessor شمسی برای created_at در مدل Order بنویس و در لیست سفارش‌ها نمایش بده.
  2. فرم «فیلتر بر اساس تاریخ» بساز که تاریخ شمسی بگیرد و در کوئری به میلادی تبدیل کند.
تمرین ۳
  1. در فرم ثبت‌نام، شماره‌ی موبایل با ارقام فارسی بزن و ثبت‌نام را با prepareForValidation موفق کن.
  2. تست بنویس که fa_slug نیم‌فاصله و علامت‌ها را درست مدیریت می‌کند.
