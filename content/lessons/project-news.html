پروژه‌ی دوم: سایت خبری

سایت خبری کامل با پنل ادمین، کاربران، دیدگاه و آپلود تصویر. این پروژه برای دوره‌ی «Laravel از 0 تا 1000» توسط Rayvo (رایبد اکبرلو) ساخته شده است.

۱. دانلود با یک کلیک

⬇ دانلود laravel-news-source.zip

۳۳ فایل: مدل‌ها، مایگریشن‌ها، کنترلرها، ویوها، پنل مدیریت، داده‌ی آزمایشی و تست. این zip یک «لایه‌ی روی لاراول» است، نه پروژه‌ی کامل؛ پوشه‌ی vendor را Composer نصب می‌کند.

این فایل‌ها بازنویسی می‌شوند: routes/web.php، app/Models/User.php و database/seeders/DatabaseSeeder.php. فقط روی پروژه‌ی تازه استخراج کن.

۲. نصب و اجرا (گام‌به‌گام)

اول XAMPP یا Laragon را باز و Apache/MySQL را Start کن (برای SQLite پیش‌فرض لازم نیست). ترمینال VS Code را در پوشه‌ای که می‌خواهی پروژه آنجا ساخته شود باز کن. PHP 8.3+ و Composer 2 لازم است.

کدترمینال
composer create-project laravel/laravel laravel-news
cd laravel-news

# ویندوز (PowerShell):
tar -xf "$env:USERPROFILE\Downloads\laravel-news-source.zip" -C .
# مک / لینوکس:
unzip -o ~/Downloads/laravel-news-source.zip -d .

php artisan migrate --seed
php artisan storage:link
php artisan serve

۳. اگر با MySQL (XAMPP یا Laragon) کار می‌کنی

در http://127.0.0.1/phpmyadmin/ دیتابیسی به اسم laravel_news با collation برابر utf8mb4_unicode_ci بساز و این مقدارها را در .env بگذار. بعد دیتابیس را از نو بساز:

کد.env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel_news
DB_USERNAME=root
DB_PASSWORD=

php artisan migrate:fresh --seed

۴. حساب‌ها و آدرس‌ها

مدیر: admin@news.test با گذرواژه‌ی password (پس از ورود به /admin می‌روی). کاربر عادی: user@news.test با password. آدرس‌ها: / خانه، /category/1 دسته، /posts/1 خبر، /login و /register، /admin پنل مدیریت (فقط ادمین).

۵. امکانات پروژه

وبسایت عمومی: فهرست خبر با صفحه‌بندی، جستجو، فیلتر دسته، بازدید خبر. کاربر: ثبت‌نام و ورود، ثبت دیدگاه (پس از تأیید ادمین نمایش داده می‌شود). پنل ادمین: داشبورد آماری، CRUD خبر با آپلود تصویر و پیش‌نویس/انتشار، مدیریت دسته‌ها، تأیید و حذف دیدگاه‌ها. امنیت: نقش ادمین با Middleware، محدودیت نرخ ورود و دیدگاه، role خارج از fillable، escape خروجی.

۶. هر بخش به کدام درس برمی‌گردد

روت و کنترلر (درس ۲ و ۳)، Blade و کامپوننت (۵ و ۶)، Migration (۷)، Eloquent و روابط (۸ و ۹)، Validation (۱۰)، Middleware (۱۱)، Auth (۱۲)، آپلود (۱۴)، امنیت (۱۵).

۷. اجرای تست

کدتست
php artisan test

۸. تمرین و قدم بعدی

فیلد برچسب (Tag) با رابطه‌ی چندبه‌چند اضافه کن؛ تاریخ شمسی را با درس فارسی‌سازی به خبرها بده؛ ایمیل اطلاع به ادمین هنگام دیدگاه جدید بفرست (Notification)؛ API خبرها را با Sanctum بساز؛ نقش «ویراستار» را با Policy اضافه کن.

اشتباه‌های رایج

  1. استخراج zip بیرون از پوشه‌ی laravel-news؛ پوشه‌ی app باید کنار artisan باشد.
  2. فراموش‌کردن php artisan storage:link و ۴۰۴ شدن تصویرها.
  3. روشن‌نبودن MySQL هنگام استفاده از دیتابیس MySQL (خطای connection refused).
