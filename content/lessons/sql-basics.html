۱

دیتابیس، جدول و ستون

دیتابیس جایی است که داده‌ی ماندگار برنامه ذخیره می‌شود. یک دیتابیس چند جدول دارد؛ هر جدول مثل یک شیت اکسل است: ستون‌ها ویژگی‌ها و سطرها رکوردها هستند. ما از MySQL (یا MariaDB که با XAMPP می‌آید) استفاده می‌کنیم و زبان صحبت با آن SQL است.

نوع ستونبرای چه؟مثال
INT / BIGINTعدد صحیحid، تعداد، قیمت (تومان)
VARCHAR(255)متن کوتاهنام، ایمیل، عنوان
TEXTمتن بلندتوضیحات، متن مقاله
DECIMAL(10,2)عدد اعشاری دقیقمبلغ‌های ارزی
BOOLEANبله/خیرفعال بودن
TIMESTAMP / DATETIMEتاریخ و زمانcreated_at
قیمت را چطور ذخیره کنیم؟

برای تومان/ریال از عدد صحیح (BIGINT) استفاده کن، نه FLOAT؛ اعشاری‌های ساده خطای گرد‌کردن دارند و در پول قابل‌قبول نیست.

۲

ساخت دیتابیس در phpMyAdmin

  1. XAMPP را اجرا و Apache و MySQL را Start کن.
  2. آدرس http://localhost/phpmyadmin را باز کن.
  3. از سمت چپ New را بزن، نام rayvo_shop و collation را utf8mb4_unicode_ci بگذار و Create کن.
  4. تب SQL را باز کن؛ کدهای این درس را آنجا می‌چسبانیم و Go می‌زنیم.
حتماً utf8mb4

اگر collation را utf8mb4_unicode_ci نگذاری، فارسی و ایموجی ممکن است به‌صورت ؟؟؟ ذخیره شود. لاراول هم پیش‌فرضش utf8mb4 است.

۳

ساخت جدول (CREATE TABLE)

کدsql
CREATE TABLE categories (
    id   INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE products (
    id          INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    category_id INT UNSIGNED NOT NULL,
    title       VARCHAR(200) NOT NULL,
    price       BIGINT UNSIGNED NOT NULL,
    stock       INT UNSIGNED NOT NULL DEFAULT 0,
    created_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (category_id) REFERENCES categories(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
  • PRIMARY KEY: شناسه‌ی یکتای هر سطر. AUTO_INCREMENT یعنی خودش ۱، ۲، ۳... می‌دهد.
  • NOT NULL: این ستون نباید خالی باشد.
  • FOREIGN KEY: «کلید خارجی»؛ می‌گوید category_id حتماً باید یکی از idهای جدول categories باشد. این همان پایه‌ی «رابطه» در Eloquent است.

خواندن داده (SELECT)

کدsql
SELECT * FROM products;                          -- همه‌ی ستون‌ها و سطرها
SELECT title, price FROM products;               -- فقط دو ستون

SELECT title, price
FROM products
WHERE price > 500000
ORDER BY price DESC;
خروجیخروجی
هدفون | 1200000
کیبورد | 850000
اسپیکر | 680000
کدsql
SELECT title FROM products WHERE stock = 0;            -- ناموجودها
SELECT title FROM products ORDER BY price DESC LIMIT 2;   -- ۲ گران‌ترین
SELECT title FROM products WHERE title LIKE 'ک%';       -- شروع با «ک»
SELECT title FROM products WHERE price BETWEEN 400000 AND 700000;
SELECT title FROM products WHERE category_id IN (1, 2) AND stock > 0;
ترتیب نوشتن

SELECT ← FROM ← WHERE ← GROUP BY ← ORDER BY ← LIMIT. این ترتیب را حفظ کن؛ در Query Builder لاراول هم همین است (select()->where()->orderBy()->limit()).

۶

ویرایش و حذف (UPDATE و DELETE)

کدsql
UPDATE products SET stock = stock + 20 WHERE id = 3;
UPDATE products SET price = price * 1.1 WHERE category_id = 1;

DELETE FROM products WHERE id = 4;
خطرناک‌ترین اشتباه SQL

UPDATE یا DELETE بدون WHERE روی همه‌ی سطرها اثر می‌گذارد! قبل از اجرا همان شرط را با یک SELECT امتحان کن و ببین دقیقاً چند سطر انتخاب می‌شود. در پروژه‌های واقعی حتماً بکاپ داشته باش.

۷

JOIN: پیوند جدول‌ها

کدsql
SELECT p.title, c.name AS category
FROM products p
JOIN categories c ON c.id = p.category_id
ORDER BY p.id;
خروجیخروجی
کیبورد | لوازم جانبی
ماوس | لوازم جانبی
هدفون | صوتی
اسپیکر | صوتی

JOIN هر سطر محصول را با سطر مربوط به دسته‌اش «جفت» می‌کند. LEFT JOIN هم سطرهای سمت چپ را نگه می‌دارد حتی اگر جفتی نداشته باشند (مثلاً دسته‌ی بدون محصول).

توابع تجمیعی و GROUP BY

کدsql
SELECT COUNT(*) AS n, MAX(price) AS max_price, MIN(price) AS min_price, SUM(stock) AS total_stock
FROM products;
خروجیخروجی
4 | 1200000 | 420000 | 42
کدsql
SELECT c.name, COUNT(*) AS n, AVG(p.price) AS avg_price, SUM(p.stock) AS total_stock
FROM products p
JOIN categories c ON c.id = p.category_id
GROUP BY c.id, c.name;
خروجیخروجی
لوازم جانبی | 2 | 635000.0000 | 35
صوتی | 2 | 940000.0000 | 7
گزارش‌گیری

همین کوئری‌ها پایه‌ی داشبورد ادمین در پروژه‌های دوره هستند: تعداد سفارش، جمع فروش، پرفروش‌ترین‌ها.

۹

اتصال از PHP با PDO (و ریشه‌ی SQL Injection)

کدphp
<?php
$pdo = new PDO(
    "mysql:host=localhost;dbname=rayvo_shop;charset=utf8mb4",
    "root",
    "",                       // در XAMPP رمز پیش‌فرض خالی است
    [
        PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    ]
);

// ✅ درست: Prepared Statement
$stmt = $pdo->prepare("SELECT title, price FROM products WHERE price > :min ORDER BY price");
$stmt->execute(["min" => 500000]);

foreach ($stmt as $row) {
    echo $row["title"], ": ", number_format($row["price"]), "\n";
}
هرگز ورودی کاربر را داخل رشته‌ی SQL نچسبان

کدی مثل "... WHERE title = '$_GET[q]'" به مهاجم اجازه می‌دهد کوئری را عوض کند (SQL Injection). با Prepared Statement مقدارها جدا از دستور ارسال می‌شوند و این حمله ممکن نیست. Eloquent و Query Builder لاراول خودکار همین کار را می‌کنند؛ ولی باید بدانی چرا.

۱۰

اشتباه‌های رایج

  1. فراموش‌کردن WHERE در UPDATE/DELETE.
  2. نگذاشتن کوتیشن دور متن ('سلام') یا استفاده از کوتیشن اشتباه برای نام ستون (باید backtick باشد).
  3. collation غیر از utf8mb4 و خراب‌شدن فارسی.
  4. ذخیره‌ی قیمت به‌صورت متن یا FLOAT.
  5. حذف سطر دسته‌ای که محصول دارد؛ کلید خارجی اجازه نمی‌دهد (و درست است!).
★

تمرین‌ها

تمرین ۱: SELECT
  1. محصولاتی که موجودی‌شان کمتر از ۱۰ است را بیاور.
  2. گران‌ترین محصول هر دسته را با MAX و GROUP BY پیدا کن.
تمرین ۲: جدول تازه
  1. جدول customers با ستون‌های id، name، phone (یکتا) و created_at بساز.
  2. سه مشتری اضافه کن و با LIKE جست‌وجو کن.
تمرین ۳: سفارش
  1. جدول orders با کلید خارجی به customers و جدول order_items برای محصول‌های هر سفارش طراحی کن (رابطه‌ی چندبه‌چند).
  2. کوئری بنویس که جمع مبلغ هر مشتری را نشان بدهد.
