پروژه‌ی سوم: سیستم رزرو وقت

سیستم رزرو نوبت آنلاین با انتخاب خدمت، نمایش ساعت‌های خالی، پنل کاربر و پنل ادمین. این پروژه برای دوره‌ی «Laravel از 0 تا 1000» توسط Rayvo (رایبد اکبرلو) ساخته شده است.

۱. دانلود با یک کلیک

⬇ دانلود laravel-booking-source.zip

58 فایل: مدل، مایگریشن، کنترلر، ویو، پنل مدیریت، داده‌ی آزمایشی و تست. این zip یک «لایه‌ی روی لاراول» است، نه پروژه‌ی کامل؛ پوشه‌ی vendor را Composer نصب می‌کند.

این فایل‌ها بازنویسی می‌شوند: routes/web.php، app/Models/User.php و database/seeders/DatabaseSeeder.php. فقط روی پروژه‌ی تازه استخراج کن.

۲. نصب و اجرا

PHP 8.3+ و Composer 2 لازم است. دیتابیس پیش‌فرض SQLite است و چیزی برای راه‌اندازی ندارد. ترمینال VS Code را در پوشه‌ی دلخواه باز کن:

کدترمینال
composer create-project laravel/laravel laravel-booking
cd laravel-booking

# ویندوز (PowerShell):
tar -xf "$env:USERPROFILE\Downloads\laravel-booking-source.zip" -C .
# مک / لینوکس:
unzip -o ~/Downloads/laravel-booking-source.zip -d .

php artisan migrate --seed
php artisan storage:link
php artisan serve

۳. اگر با MySQL (XAMPP یا Laragon) کار می‌کنی

اگر با MySQL کار می‌کنی، XAMPP یا Laragon را باز و MySQL را Start کن. در http://127.0.0.1/phpmyadmin/ دیتابیسی به اسم laravel_booking با collation برابر utf8mb4_unicode_ci بساز، این مقدارها را در .env بگذار و دیتابیس را از نو بساز:

کد.env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel_booking
DB_USERNAME=root
DB_PASSWORD=

php artisan migrate:fresh --seed

۴. حساب‌ها و آدرس‌ها

مدیر: admin@book.test و کاربر: user@book.test با گذرواژه‌ی password. آدرس‌ها: / خانه، /book رزرو، /my-bookings نوبت‌های من، /admin پنل مدیریت.

۵. امکانات

کاربر: انتخاب خدمت و روز، دیدن ساعت‌های خالی به‌صورت زنده (JavaScript و JSON)، ثبت نوبت، لغو تا چند ساعت قبل. ادمین: داشبورد، CRUD خدمات (مدت و قیمت)، تغییر وضعیت نوبت (در انتظار، تأیید، انجام، لغو)، ثبت روزهای تعطیل. منطق: جلوگیری از رزرو هم‌پوشان، حداقل فاصله از «الان»، قیمت snapshot، محدودیت نرخ.

۶. تنظیم ساعت کار

همه‌ی تنظیمات در یک فایل است؛ ساعت شروع و پایان، فاصله‌ی نوبت‌ها، روزهای تعطیل هفته و مهلت لغو:

کدconfig
// config/booking.php
'open' => '09:00',
'close' => '17:00',
'step' => 30,
'off_days' => [5],   // 5 = جمعه
'cancel_hours' => 2,

۷. قلب پروژه: محاسبه‌ی ساعت‌های خالی

فایل app/Services/SlotService.php: از ساعت شروع تا پایان کار جلو می‌رود، هر بازه را با نوبت‌های ثبت‌شده مقایسه می‌کند و شرط هم‌پوشانی start < end_other و end > start_other را می‌سنجد. ثبت نوبت هم دوباره همین بررسی را داخل تراکنش انجام می‌دهد، چون ممکن است بین دیدن ساعت و ثبت، دیگری گرفته باشد. نکته‌ی صادقانه: برای ترافیک خیلی سنگین (چند ثبت هم‌زمان) باید قفل سطح دیتابیس اضافه کنی؛ تمرین خوبی برای سطح ۳ است.

۸. هر بخش به کدام درس برمی‌گردد

روت و کنترلر (۲ و ۳)، Blade و کامپوننت (۵ و ۶)، Migration (۷)، Eloquent (۸ و ۹)، Validation (۱۰)، Middleware (۱۱)، Auth (۱۲)، Service (سطح ۳)، تست (سطح ۲).

۹. اجرای تست و تمرین

کدتست
php artisan test

۱۰. تمرین

چند پزشک یا کارمند اضافه کن و هر نوبت را به یکی نسبت بده؛ ایمیل تأیید با Notification و صف بفرست؛ یادآوری روز قبل را با Scheduler بساز؛ تاریخ شمسی نشان بده؛ درگاه پرداخت برای پیش‌پرداخت وصل کن.

اشتباه‌های رایج

  1. استخراج zip بیرون از پوشه‌ی پروژه؛ پوشه‌ی app باید کنار artisan باشد.
  2. نگرفتن ساعت‌های خالی به‌خاطر ساعت کار یا روز تعطیل در config/booking.php.
  3. روشن‌نبودن MySQL هنگام استفاده از دیتابیس MySQL.
