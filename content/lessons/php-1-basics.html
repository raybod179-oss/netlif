PHP چیست و کجا اجرا می‌شود؟

PHP یک زبان برنامه‌نویسی سمت سرور است؛ یعنی کدش روی سرور اجرا می‌شود و خروجی (معمولاً HTML) برای مرورگر فرستاده می‌شود. لاراول هم فقط یک مجموعه‌ی بزرگ و منظم از کدهای PHP است؛ پس هرچه در این درس‌ها محکم یاد بگیری، در کل دوره به کارت می‌آید.

برای اجرای کد دو راه داری و ما از هر دو استفاده می‌کنیم:

  • از طریق مرورگر: فایل را داخل پوشه‌ی htdocs در XAMPP (یا www در Laragon) بگذار و آدرس http://localhost/test.php را باز کن.
  • از طریق ترمینال: داخل پوشه‌ی فایل بنویس php test.php. برای تمرین‌های کوتاه سریع‌ترین راه همین است.
کدbash
php -v
# باید نسخه‌ی 8.3 یا بالاتر را ببینی. اگر دستور شناخته نشد، متغیر PATH در درس «راه‌اندازی محیط کار» را دوباره چک کن.
نسخه‌ی PHP

لاراول ۱۲ به PHP 8.2 یا بالاتر نیاز دارد. این دوره روی PHP 8.3 و بالاتر نوشته شده تا با آخرین قابلیت‌ها هم‌خوان باشد.

اولین فایل PHP

یک فایل به نام hello.php بساز. کد PHP همیشه داخل تگ <?php نوشته می‌شود و هر دستور با ; تمام می‌شود.

کدphp
<?php

// این یک کامنت تک‌خطی است
# این هم کامنت است (کمتر استفاده می‌شود)
/* این کامنت
   چندخطی است */

echo "سلام Rayvo!";
echo "<br>";
echo "اولین برنامه‌ی PHP من";
خروجیخروجی
سلام Rayvo!
اولین برنامه‌ی PHP من
echo یا print؟

هر دو متن چاپ می‌کنند ولی echo سریع‌تر و رایج‌تر است. در فایل‌هایی که فقط PHP دارند، تگ پایانی ?> را ننویس؛ این استاندارد لاراول است و جلوی خطای «فاصله‌ی اضافه» را می‌گیرد.

۳

متغیرها و انواع داده

متغیر یک «جعبه‌ی نام‌دار» برای نگه‌داشتن مقدار است. نام متغیر با $ شروع می‌شود و حساس به بزرگی و کوچکی حروف است ($name با $Name فرق دارد).

کدphp
<?php
$name   = "علی";        // string  (متن)
$age    = 24;           // int     (عدد صحیح)
$price  = 199.5;        // float   (عدد اعشاری)
$isPaid = true;         // bool    (درست/نادرست)
$nothing = null;        // null    (هیچ)

var_dump($name, $age, $price, $isPaid, $nothing);
خروجیخروجی
string(6) "علی"
int(24)
float(199.5)
bool(true)
NULL

var_dump() بهترین دوست تو برای اشکال‌زدایی است: هم مقدار را نشان می‌دهد هم نوع را. (در متن فارسی طول رشته بر حسب بایت است، برای همین عدد ۶ می‌بینی.)

قاعده‌ی نام‌گذاری

نام متغیر را انگلیسی، واضح و با camelCase بنویس: $totalPrice، نه $tp. کدی که بعد از یک ماه هم خودت بفهمی، کد خوبی است.

کار با رشته‌ها

کدphp
<?php
$first = "رایبد";
$last  = "اکبرلو";

// الحاق با نقطه
$full = $first . " " . $last;

// داخل کوتیشن دوتایی، متغیر مستقیم جایگزین می‌شود
echo "نام کامل: $full\n";
echo 'در تک‌کوتیشن: $full\n';   // جایگزین نمی‌شود!

$email = "info@rayvo.dev";
echo strlen($email), "\n";                 // 14
echo strtoupper($email), "\n";             // INFO@RAYVO.DEV
echo str_contains($email, "@") ? "ایمیل معتبر به نظر می‌رسد" : "@ ندارد", "\n";
echo str_replace("info", "hello", $email), "\n";
echo substr($email, 0, 4), "\n";           // info
خروجیخروجی
نام کامل: رایبد اکبرلو
در تک‌کوتیشن: $full\n14
INFO@RAYVO.DEV
ایمیل معتبر به نظر می‌رسد
hello@rayvo.dev
info
برای متن فارسی

توابع معمولی مثل strlen و strtoupper بایت‌محورند و برای فارسی دقیق نیستند. برای طول و برش متن فارسی از mb_strlen() و mb_substr() استفاده کن.

عملگرها

نوععملگرهامثال
حسابی+ - * / % **10 % 3 ← ۱ ، 2 ** 3 ← ۸
مقایسه== === != !== < > <= >=5 === "5" ← false
منطقی&& || !$a > 1 && $b < 5
ادغام null??$name ?? "مهمان"
انتساب ترکیبی+= -= .= ++ --$n++
همیشه === بزن

== قبل از مقایسه نوع‌ها را تبدیل می‌کند و غافلگیرت می‌کند (مثلاً 0 == "abc" در نسخه‌های قدیمی true بود). === هم مقدار و هم نوع را چک می‌کند و امن‌تر است. در لاراول هم همین را می‌بینی.

کدphp
<?php
$user = null;
echo $user ?? "مهمان";      // مهمان

$score = 8;
$score += 2;                  // ۱۰
$score++;                     // ۱۱
echo $score;
۶

شرط‌ها: if، match و عملگر سه‌تایی

کدphp
<?php
$score = 17;

if ($score >= 18) {
    echo "عالی";
} elseif ($score >= 10) {
    echo "قبول";
} else {
    echo "مردود";
}

// عملگر سه‌تایی: برای شرط‌های کوتاه
$status = $score >= 10 ? "قبول" : "مردود";

// match: جایگزین مرتب‌تر switch (از PHP 8)
$label = match (true) {
    $score >= 18 => "عالی",
    $score >= 14 => "خوب",
    $score >= 10 => "متوسط",
    default      => "ضعیف",
};
echo $label;   // خوب

match مقدار برمی‌گرداند، سخت‌گیرانه مقایسه می‌کند (مثل ===) و اگر هیچ شرطی جور نشود خطا می‌دهد؛ به همین دلیل از switch امن‌تر است.

حلقه‌ها

کدphp
<?php
// for: وقتی تعداد تکرار را می‌دانی
for ($i = 1; $i <= 5; $i++) {
    echo "$i ";
}
echo "\n";

// while: تا وقتی شرط برقرار است
$n = 3;
while ($n > 0) {
    echo "شمارش معکوس: $n\n";
    $n--;
}

// break و continue
for ($i = 1; $i <= 10; $i++) {
    if ($i % 2 === 0) continue;   // زوج‌ها را رد کن
    if ($i > 7) break;            // از ۷ بیشتر شد، تمام
    echo $i, " ";
}
خروجیخروجی
1 2 3 4 5 
شمارش معکوس: 3
شمارش معکوس: 2
شمارش معکوس: 1
1 3 5 7
foreach

حلقه‌ی اصلی برای آرایه‌هاست و در درس بعد (آرایه و تابع) کامل کار می‌کنیم؛ در لاراول بیشترین استفاده را از آن می‌کنی.

گام پروژه: جدول ضرب و کارنامه

حالا همه‌ی آموخته‌ها را با هم بزن. فایل mini.php بساز:

کدphp
<?php
// ۱) جدول ضرب عدد ۷
$base = 7;
for ($i = 1; $i <= 10; $i++) {
    echo "$base × $i = " . ($base * $i) . "\n";
}

// ۲) کارنامه
$math = 16; $physics = 12; $english = 19;
$avg = ($math + $physics + $english) / 3;

$grade = match (true) {
    $avg >= 17 => "ممتاز",
    $avg >= 14 => "خیلی خوب",
    $avg >= 10 => "قبول",
    default    => "مردود",
};

echo "میانگین: " . round($avg, 2) . " ← $grade\n";
خروجیخروجی
7 × 1 = 7
...
7 × 10 = 70
میانگین: 15.67 ← خیلی خوب
۹

اشتباه‌های رایج مبتدی‌ها

  1. فراموش کردن ; آخر دستور (خطای Parse error).
  2. فراموش کردن $ قبل از نام متغیر.
  3. استفاده از = (انتساب) به‌جای === (مقایسه) داخل if.
  4. نوشتن متغیر داخل تک‌کوتیشن و تعجب از اینکه جایگزین نمی‌شود.
  5. ذخیره‌ی فایل با پسوند .html یا .txt و دیدن خود کد در مرورگر؛ پسوند باید .php باشد و از طریق localhost اجرا شود نه دوبار کلیک روی فایل.
  6. ذخیره‌ی فایل با انکودینگ غیر UTF-8 و به‌هم‌ریختگی فارسی؛ در VS Code پایین صفحه باید UTF-8 باشد.
وقتی خطا دیدی

پیام خطا را بخوان: شماره‌ی خط را می‌گوید. معمولاً مشکل همان خط یا خط قبلش است. اگر گیر کردی، ابتدا var_dump بزن و ببین مقدار واقعاً چیست.

تمرین‌ها

تمرین ۱: سن و دسته‌بندی
  1. سن را در متغیر $age بگذار. اگر زیر ۱۲ بود «کودک»، ۱۲ تا ۱۷ «نوجوان»، ۱۸ تا ۶۴ «بزرگسال» و بالاتر «سالمند» چاپ کن (با match).
  2. همین را یک‌بار با if / elseif هم بنویس و مقایسه کن کدام خواناتر است.
تمرین ۲: حلقه
  1. مجموع اعداد ۱ تا ۱۰۰ را با for حساب کن (جواب: ۵۰۵۰).
  2. همه‌ی مضرب‌های ۳ بین ۱ تا ۵۰ را چاپ کن.
  3. با دو حلقه‌ی تودرتو یک مثلث ستاره‌ای ۵ ردیفی بکش.
تمرین ۳: تبدیل واحد
  1. دمای سانتی‌گراد را در متغیر بگذار و معادل فارنهایت را حساب کن (C × 9/5 + 32) و با round گرد کن.
  2. اگر بالای ۳۵ درجه بود پیام «هوا گرم است» چاپ کن.
