۱

وب چطور کار می‌کند؟

وقتی آدرسی را در مرورگر می‌زنی، سه بازیگر وارد کار می‌شوند. فهمیدن همین سه‌تا نصف مسیر یادگیری لاراول است:

مرورگر (کلاینت)← درخواست → سرور وب + PHP← کوئری → دیتابیس (MySQL)
  • مرورگر درخواست می‌فرستد: «صفحه‌ی محصولات را بده».
  • سرور وب (Apache) با PHP کد ما را اجرا می‌کند. لاراول همین‌جا زندگی می‌کند.
  • دیتابیس اطلاعات (کاربران، محصولات، سفارش‌ها) را نگه می‌دارد.

روی کامپیوتر خودت باید هر سه را داشته باشی. بسته‌هایی مثل XAMPP و Laragon همین سه را یک‌جا نصب می‌کنند.

آدرس localhost

آدرس‌های localhost و 127.0.0.1 هر دو یعنی «همین کامپیوتر خودم». سایت‌هایی که اینجا می‌سازیم فقط روی دستگاه خودت دیده می‌شوند و کسی از اینترنت به آن‌ها دسترسی ندارد.

۲

نصب VS Code و افزونه‌ها

VS Code ویرایشگر رایگان و محبوبی است که کدها را در آن می‌نویسیم.

  1. از code.visualstudio.com نسخه‌ی ویندوز (یا مک/لینوکس) را دانلود کن.
  2. هنگام نصب این دو گزینه را فعال کن: «Add to PATH» و «Open with Code» (راست‌کلیک روی پوشه‌ها).
  3. VS Code را باز کن و از ستون کناری روی آیکن مربع‌ها (Extensions) بزن.

این افزونه‌ها را نصب کن (نام را جستجو کن):

افزونهچه کمکی می‌کند؟
PHP Intelephenseپیشنهاد خودکار کد PHP و پیدا کردن خطا
Laravel Blade Snippetsرنگ‌بندی و میان‌بُر برای فایل‌های .blade.php
Laravel (افزونه‌ی رسمی)پیمایش روت‌ها، ویوها و تنظیمات در پروژه
DotENVرنگ‌بندی فایل .env
اگر افزونه‌ای پیدا نشد

گاهی نام افزونه‌ها یا ناشرشان عوض می‌شود. اگر دقیقاً همین نام را نیافتی، یکی از نزدیک‌ترین نتایج با تعداد دانلود بالا را انتخاب کن؛ برای ادامه‌ی دوره هیچ‌کدام اجباری نیستند.

۳

XAMPP یا Laragon؟

هر دو سرور محلی‌اند. فقط یکی را نصب کن؛ با هم تداخل پیدا می‌کنند.

XAMPP

  • معروف‌ترین؛ آموزش‌های زیادی دارد
  • پنل ساده برای روشن/خاموش کردن Apache و MySQL
  • phpMyAdmin به‌صورت آماده همراهش نصب می‌شود
  • ممکن است نسخه‌ی PHP آن برای لاراول قدیمی باشد

Laragon (ویندوز)

  • سبک و سریع؛ تعویض نسخه‌ی PHP آسان
  • همراه Composer و ابزارهای دیگر می‌آید
  • ساخت پروژه‌ی لاراول با چند کلیک
  • برای لاراول معمولاً راحت‌تر است
قاعده‌ی تصمیم‌گیری

اول XAMPP را نصب کن و با دستور php -v نسخه‌ی PHP را ببین. اگر پایین‌تر از نسخه‌ی موردنیاز لاراول بود (این دوره PHP ۸.۳ به بالا را فرض می‌کند)، XAMPP را حذف کن و Laragon نصب کن. هر دو را هم‌زمان روشن نگه نداری.

مک: ابزارهایی مثل Laravel Herd یا Homebrew همین نقش را دارند. لینوکس: PHP و MySQL را از مخزن توزیع خودت نصب کن.

۴

نصب و راه‌اندازی XAMPP

  1. از سایت apachefriends.org نسخه‌ی ویندوز را دانلود و نصب کن. مسیر پیش‌فرض C:\xampp مناسب است.
  2. «XAMPP Control Panel» را اجرا کن (بهتر است به‌صورت Administrator).
  3. جلوی Apache و MySQL دکمه‌ی Start را بزن. وقتی سبز شدند، آماده‌اند.
  4. در مرورگر این آدرس را باز کن؛ باید صفحه‌ی خوش‌آمدگویی XAMPP را ببینی:
آدرسمرورگر
http://127.0.0.1/

اضافه کردن PHP به PATH

تا بتوانیم در ترمینال دستور php را بزنیم، مسیر PHP را به PATH ویندوز اضافه می‌کنیم:

  1. در Start بنویس: «Edit the system environment variables».
  2. دکمه‌ی Environment Variables ← در بخش System variables، Path را انتخاب و Edit بزن.
  3. New بزن و این مسیر را اضافه کن، سپس همه‌ی پنجره‌ها را با OK ببند:
مسیرPATH
C:\xampp\php

یک ترمینال جدید (PowerShell) باز کن و بزن:

کدترمینال
php -v

باید نسخه‌ی PHP چاپ شود. اگر عدد کمتر از ۸.۳ بود، به بخش بعدی (Laragon) برو.

اولین فایل PHP

پوشه‌ی C:\xampp\htdocs محل فایل‌های وب است. یک فایل به نام test.php در آن بساز:

C:\xampp\htdocs\test.phpPHP
<?php
echo 'سلام Rayvo! PHP کار می‌کند ';
echo '<br>نسخه‌ی PHP: ' . PHP_VERSION;

آدرس http://127.0.0.1/test.php را باز کن. اگر پیام را دیدی، سرور و PHP درست کار می‌کنند. پس از تست، فایل را پاک کن.

۵

نصب و راه‌اندازی Laragon

اگر XAMPP نصب نکردی یا PHP آن قدیمی بود، از این بخش استفاده کن.

  1. اگر XAMPP روی سیستم هست، اول آن را متوقف و حذف کن.
  2. از laragon.org نسخه‌ی Full را دانلود و نصب کن (ترجیحاً مسیر C:\laragon).
  3. Laragon را باز کن و دکمه‌ی Start All را بزن؛ Apache (یا Nginx) و MySQL روشن می‌شوند.
  4. روی دکمه‌ی Terminal بزن. ترمینال Laragon php، composer و git را بدون تنظیم PATH می‌شناسد.
کدترمینال داخل Laragon
php -v
composer -V
mysql --version

پوشه‌ی پروژه‌ها در Laragon C:\laragon\www است. یک پروژه‌ی لاراول می‌تواند آنجا ساخته شود؛ اما در این دوره ترجیح می‌دهیم پروژه‌ها را خودمان در پوشه‌ی ساده‌ای مثل D:\projects نگه داریم و با php artisan serve اجرا کنیم تا در هر دو حالت (XAMPP/Laragon) یکسان کار کنیم.

phpMyAdmin در Laragon

Laragon به‌صورت پیش‌فرض ابزار دیتابیس خودش (HeidiSQL) را دارد. اگر phpMyAdmin را ترجیح می‌دهی، از منوی Laragon (راست‌کلیک روی آیکن) بخش ابزارها / نصب سریع را نگاه کن و phpMyAdmin را اضافه کن. محل دقیق منو در نسخه‌های مختلف کمی فرق می‌کند.

۶

phpMyAdmin و ساخت دیتابیس

phpMyAdmin یک صفحه‌ی وب است که دیتابیس MySQL را با ماوس مدیریت می‌کند. با XAMPP روشن (Apache و MySQL سبز) این آدرس را باز کن:

آدرسمرورگر
http://127.0.0.1/phpmyadmin/

بدون رمز وارد می‌شوی؛ کاربر پیش‌فرض root و رمز آن خالی است. این تنظیم فقط برای کامپیوتر شخصی مناسب است.

ساخت یک دیتابیس

  1. روی New (جدید) در ستون چپ بزن.
  2. نام دیتابیس: laravel_course
  3. مقابل آن کادر Collation را روی utf8mb4_unicode_ci بگذار (برای پشتیبانی کامل از فارسی و ایموجی).
  4. Create را بزن.

اتصال لاراول به این دیتابیس

در درس بعد پروژه‌ی لاراول را می‌سازیم. اگر بخواهی به‌جای SQLite از MySQL استفاده کنی، در فایل .env پروژه این مقدارها را می‌گذاری:

کدفایل .env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laravel_course
DB_USERNAME=root
DB_PASSWORD=

بعد با php artisan migrate جدول‌ها ساخته می‌شوند و همان لحظه در phpMyAdmin (با رفرش) دیده می‌شوند.

هشدار امنیتی

هرگز روی سرور واقعی کاربر root بدون رمز نگذار و phpMyAdmin را بدون محافظت در دسترس همه قرار نده.

۷

Composer، Git و Node

Composer

مدیر بسته‌های PHP است. لاراول و همه‌ی کتابخانه‌هایش با آن نصب می‌شوند. (در Laragon همراه است.) در XAMPP باید جداگانه از getcomposer.org نصب‌کننده‌ی ویندوز را دانلود کنی؛ در حین نصب، مسیر php.exe را به آن نشان بده. بعد در ترمینال جدید:

کدترمینال
composer -V

Git

تاریخچه‌ی تغییرات کد را ذخیره می‌کند و برای کار تیمی و گیت‌هاب لازم است. از git-scm.com نصب کن (تنظیمات پیش‌فرض خوب‌اند) و یک بار نام و ایمیل خودت را معرفی کن:

کدترمینال
git --version
git config --global user.name "نام تو"
git config --global user.email "you@example.com"

سه دستور اصلی که در پروژه‌ها زیاد استفاده می‌کنیم:

کدترمینال
git init            # شروع نگهداری تاریخچه در پوشه
git add .           # همه‌ی تغییرات را آماده‌ی ثبت کن
git commit -m "پیام"  # یک نقطه‌ی بازگشت بساز

Node.js (اختیاری فعلاً)

برای ساخت CSS و جاوااسکریپت پروژه‌های لاراول (Vite) لازم می‌شود. نسخه‌ی LTS را از nodejs.org نصب کن و با node -v تست کن. فروشگاه این دوره بدون Node هم اجرا می‌شود.

مسیر پروژه‌ها

پروژه‌ها را در مسیری بدون فاصله و بدون حروف فارسی نگه دار؛ مثلاً D:\projects\shop. مسیرهایی مثل «دسکتاپ\پروژه من» گاهی باعث خطاهای عجیب ابزارها می‌شوند.

۸

عیب‌یابی خطاهای رایج

مشکلعلت و راه‌حل
Apache روشن نمی‌شود (پورت ۸۰ اشغال)برنامه‌ی دیگری (مثل Skype یا سرویس IIS) پورت را گرفته. آن را ببند، یا در XAMPP از Config → httpd.conf پورت را به ۸۰۸۰ تغییر بده و آدرس را http://127.0.0.1:8080/ بزن.
MySQL روشن نمی‌شودمعمولاً MySQL دیگری روی سیستم در حال اجراست (از Services ویندوز بررسی کن) یا پورت ۳۳۰۶ اشغال است.
'php' is not recognizedمسیر PHP به PATH اضافه نشده، یا ترمینال را بعد از تغییر PATH دوباره باز نکرده‌ای.
'composer' is not recognizedComposer نصب نشده یا ترمینال قدیمی است. یک ترمینال جدید باز کن.
phpMyAdmin باز نمی‌شودApache باید روشن باشد. آدرس را با / آخر بزن: http://127.0.0.1/phpmyadmin/
phpMyAdmin خطای Access denied می‌دهدرمز root را تغییر داده‌ای؛ همان رمز را وارد کن یا در config.inc.php اصلاح کن.
نسخه‌ی PHP پایین‌تر از ۸.۳ استبه Laragon مهاجرت کن (بخش ۵).
آنتی‌ویروس مانع نصب می‌شودموقتاً پوشه‌ی C:\xampp یا C:\laragon را در استثناهای آنتی‌ویروس بگذار.
۹

چک‌لیست نهایی و تمرین

همه‌ی این موارد باید روی سیستم تو درست باشد تا بتوانی به درس بعد بروی:

  • VS Code نصب است و حداقل افزونه‌ی PHP Intelephense را دارد.
  • php -v نسخه‌ی ۸.۳ یا بالاتر را نشان می‌دهد.
  • composer -V کار می‌کند.
  • git --version کار می‌کند.
  • Apache و MySQL (در XAMPP یا Laragon) روشن می‌شوند.
  • صفحه‌ی http://127.0.0.1/phpmyadmin/ باز می‌شود.
  • دیتابیس laravel_course ساخته شده است.
تمرین
  1. فایل test.php را طوری تغییر بده که نام خودت و تاریخ امروز (date('Y-m-d')) را نشان دهد.
  2. در phpMyAdmin یک جدول ساده به نام notes با دو ستون id و title بساز و یک ردیف در آن وارد کن.
  3. یک پوشه‌ی D:\projects\hello بساز، داخلش git init بزن و یک commit با پیام «اولین commit» ثبت کن.
  4. اگر یکی از مراحل خطا داد، پیام خطا را در بخش «عیب‌یابی» جست‌وجو کن؛ اگر نبود، متن خطا را در گوگل بگذار و به نتایج Stack Overflow نگاه کن. این مهارت یک برنامه‌نویس واقعی است.

چیزی که از این درس بماند

  1. سایت = مرورگر + سرور (PHP) + دیتابیس؛ localhost یعنی همین کامپیوتر.
  2. فقط یک سرور محلی نصب کن: XAMPP یا Laragon؛ اگر PHP قدیمی بود Laragon.
  3. phpMyAdmin در http://127.0.0.1/phpmyadmin/ دیتابیس را به‌صورت تصویری نشان می‌دهد.
  4. مسیر پروژه‌ها بدون فاصله و حروف فارسی باشد.
  5. خطا دیدن عادی است؛ پیام خطا را بخوان، جست‌وجو کن، و دوباره امتحان کن.
