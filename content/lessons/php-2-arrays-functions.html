آرایه چیست؟

آرایه یک متغیر است که چند مقدار را کنار هم نگه می‌دارد. در لاراول همه‌جا آرایه می‌بینی: داده‌ی فرم، نتیجه‌ی دیتابیس، تنظیمات. دو نوع اصلی داریم: اندیس‌دار (کلیدها عدد از صفر) و انجمنی (کلیدها نام).

کدphp
<?php
// اندیس‌دار
$fruits = ["سیب", "موز", "پرتقال"];
echo $fruits[0], "\n";        // سیب
$fruits[] = "انار";          // اضافه به انتها
echo count($fruits), "\n";   // 4

// انجمنی (کلید => مقدار)
$user = [
    "name"  => "سارا",
    "age"   => 27,
    "email" => "sara@example.com",
];
echo $user["name"], "\n";
$user["city"] = "تهران";
unset($user["age"]);          // حذف یک کلید

// چندبعدی: آرایه‌ای از آرایه‌ها (شبیه ردیف‌های یک جدول)
$products = [
    ["id" => 1, "title" => "کیبورد", "price" => 850000],
    ["id" => 2, "title" => "ماوس",   "price" => 420000],
];
echo $products[1]["title"];   // ماوس

هر ردیف دیتابیس که از Eloquent بگیری شبیه همین $products است (فقط شیء است نه آرایه‌ی ساده). اگر این ساختار را خوب بفهمی، Collectionهای لاراول برایت آسان می‌شود.

map، filter و reduce

این سه تابع به‌جای حلقه، «تبدیل» داده را بیان می‌کنند و در لاراول (روی Collection) هر روز استفاده می‌شوند. fn یک تابع کوتاه (arrow function) است.

کدphp
<?php
$prices = [100, 250, 400, 50];

// map: روی هر عضو یک تبدیل
$withTax = array_map(fn($p) => $p * 1.1, $prices);

// filter: نگه‌داشتن اعضایی که شرط را دارند
$expensive = array_filter($prices, fn($p) => $p >= 200);

// reduce: جمع کردن همه به یک مقدار
$sum = array_reduce($prices, fn($carry, $p) => $carry + $p, 0);

echo implode(" ", $withTax), "\n";
echo implode(" ", $expensive), "\n";
echo $sum;

800
ترتیب کلیدها

array_filter کلیدهای اصلی را نگه می‌دارد (اندیس‌ها ۱ و ۲ می‌مانند). اگر اندیس تازه می‌خواهی: array_values(...).

تابع: کد قابل‌استفاده‌ی مجدد

کدphp
<?php
declare(strict_types=1);

// پارامتر، مقدار پیش‌فرض، نوع و خروجی
function priceWithTax(float $price, float $rate = 0.09): float
{
    return $price * (1 + $rate);
}

echo priceWithTax(1000), "\n";                 // 1090
echo priceWithTax(1000, 0.2), "\n";            // 1200
echo priceWithTax(rate: 0.1, price: 500), "\n"; // 550 (آرگومان نام‌دار)

// خروجی nullable
function findUser(array $users, int $id): ?array
{
    foreach ($users as $u) {
        if ($u["id"] === $id) return $u;
    }
    return null;
}

$users = [["id" => 1, "name" => "علی"]];
var_dump(findUser($users, 2));   // NULL
خروجیخروجی
1090
1200
550
NULL
type hint

نوشتن نوع پارامتر و خروجی (float، ?array) خطاها را زود نشان می‌دهد و ادیتور را باهوش‌تر می‌کند. تمام کد لاراول از همین سبک استفاده می‌کند.

Scope

متغیرهای بیرونِ تابع داخلش دیده نمی‌شوند. هر چیزی که لازم است را با پارامتر بده و با return بگیر؛ از global دوری کن.

نکته‌های مدرن PHP: spread، destructuring و include

کدphp
<?php
// spread
$a = [1, 2]; $b = [3, 4];
$all = [...$a, ...$b];             // [1,2,3,4]

function sum(int ...$nums): int { return array_sum($nums); }
echo sum(1, 2, 3, 4), "\n";         // 10

// destructuring
[$first, $second] = ["اول", "دوم"];
["name" => $n, "age" => $ag] = ["name" => "علی", "age" => 30];
echo "$first $n $ag\n";

// null-safe و ??
$config = ["db" => ["host" => "localhost"]];
echo $config["db"]["port"] ?? 3306;   // 3306

10
اول علی 30
3306

برای تقسیم کد به چند فایل از require_once "helpers.php"; استفاده می‌شود. در لاراول این کار را Composer و autoload انجام می‌دهد و تو تقریباً هیچ‌وقت require دستی نمی‌نویسی (در درس Composer می‌بینی).

گام پروژه: سبد خرید ساده

فایل cart.php بساز. هدف: جمع سبد با تخفیف.

کدphp
<?php
declare(strict_types=1);

$cart = [
    ["title" => "کیبورد", "price" => 850000, "qty" => 1],
    ["title" => "ماوس",   "price" => 420000, "qty" => 2],
    ["title" => "پد موس", "price" => 90000,  "qty" => 1],
];

function subtotal(array $cart): int
{
    return array_sum(array_map(fn($i) => $i["price"] * $i["qty"], $cart));
}

function discount(int $total): int
{
    return match (true) {
        $total >= 2000000 => (int) ($total * 0.15),
        $total >= 1000000 => (int) ($total * 0.10),
        default           => 0,
    };
}

$sub = subtotal($cart);
$off = discount($sub);

foreach ($cart as $item) {
    echo $item["title"] . " × " . $item["qty"] . " = " . number_format($item["price"] * $item["qty"]) . "\n";
}
echo "جمع: " . number_format($sub) . "\n";
echo "تخفیف: " . number_format($off) . "\n";
echo "قابل پرداخت: " . number_format($sub - $off) . "\n";

کیبورد × 1 = 850,000

جمع: 1,780,000
تخفیف: 178,000
قابل پرداخت: 1,602,000

اشتباه‌های رایج

  1. دسترسی به کلید ناموجود (Undefined array key)؛ با ?? مقدار پیش‌فرض بده یا اول isset() بزن.
  2. فراموش کردن return در تابع و دریافت null.
  3. تغییر آرایه داخل foreach و تعجب از اینکه اصلی عوض نمی‌شود (پیش‌فرض کپی است).
  4. استفاده از == برای مقایسه‌ی آرایه‌ها؛ === ترتیب و نوع را هم می‌سنجد.
  5. نوشتن حلقه‌ی دستی برای کاری که array_map/array_filter کوتاه‌تر و خواناتر انجام می‌دهد.

تمرین‌ها

تمرین ۱: آرایه
  1. آرایه‌ای از ۵ نمره بساز و میانگین، بیشترین و کمترین را چاپ کن (max، min، array_sum).
  2. فقط نمره‌های قبولی (۱۰ به بالا) را با array_filter جدا کن.
تمرین ۲: تابع
  1. تابع isEven(int $n): bool بنویس و با array_filter اعداد زوج ۱ تا ۲۰ را بگیر.
  2. تابع slugify(string $title): string بنویس که فاصله‌ها را با - عوض کند و حروف انگلیسی را کوچک کند.
تمرین ۳: ارتقای سبد
  1. هزینه‌ی ارسال ثابت ۵۰,۰۰۰ تومان اضافه کن که اگر جمع بالای ۲,۰۰۰,۰۰۰ بود صفر شود.
  2. آرایه را با usort بر اساس قیمت نزولی مرتب و چاپ کن.
