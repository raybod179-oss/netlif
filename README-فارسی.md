# دوره‌ی Laravel از 0 تا 1000 | Rayvo — نسخه‌ی Netlify

## ساختار
- `public/` : صفحه‌ی فروش، صفحه‌ی ورود، فایل‌های ظاهری و پنل مدیریت (`public/rv-admin-k9yrvqund5rutr8d7ujvpkrvwdpl/`)
- `content/` : درس‌ها و zip پروژه‌ها (**بیرون از پوشه‌ی منتشرشده**؛ فقط با جلسه‌ی معتبر ارسال می‌شود)
- `netlify/functions/` : ورود، بررسی جلسه، دروازه‌ی محتوا، API پنل
- `netlify/lib/` : امنیت (هش کد، کلید سرور، مدیر)
- `public/terms.html` : قوانین و بازگشت وجه (عددها و شرط‌های ضمانت را قبل از انتشار بخوان و با تصمیم خودت هماهنگ کن)

## راه‌اندازی (بدون هیچ متغیر محیطی)
1. ریپوی **Private** در گیت‌هاب، آپلود محتوای همین پوشه.
2. Netlify ← Import from Git ← همان ریپو ← Deploy.
3. پنل: `https://اسم-سایت.netlify.app/rv-admin-k9yrvqund5rutr8d7ujvpkrvwdpl/` ← ورود با شماره و رمز مدیر ← «وضعیت سیستم».

## امنیت
- کدهای دسترسی در انبار فقط به‌صورت **هش** نگهداری می‌شوند و بدون کلید سرور قابل خواندن نیستند. هیچ لیستی از کدها به مرورگر کاربران نمی‌رسد.
- مدیر فقط یکی است. رمز و شماره فقط به‌صورت هش (scrypt) در کد هست. از داخل پنل می‌شود رمز را عوض کرد.
- کلید امضای جلسه‌ها خودکار ساخته و در Netlify Blobs ذخیره می‌شود.
- هر کد با اولین ورود به یک مرورگر قفل می‌شود؛ غیرفعال/ریست/حذف همان لحظه اثر می‌کند.
- درس‌های پولی و zipها هرگز مستقیم سرو نمی‌شوند؛ هدرهای CSP، HSTS و ... فعال است.
- قفل ۳۰ دقیقه‌ای بعد از تلاش‌های اشتباه (ورود مدیر ۵ بار، حدس کد ۱۵ بار).

## درس‌های رایگان
فهرست، مقدمه، راه‌اندازی محیط کار و مبانی PHP ۱. برای تغییر، آرایه‌ی `FREE` را هم در `netlify/lib/auth.mjs` و هم در `public/assets/js/rayvo.js` یکسان ویرایش کنید.

## محدودیت‌ها (صادقانه)
- «یک‌بار مصرف» یعنی قفل به یک مرورگر؛ با پاک شدن کوکی یا عوض شدن گوشی، به ریست نیاز است.
- اسکرین‌شات یا کپی دستی را هیچ سیستمی صددرصد نمی‌بندد؛ واترمارک نام خریدار و امکان باطل کردن کد بازدارنده‌ی اصلی است.
- ذخیره‌سازی: Netlify Blobs نسخه‌ی 10.0.0 (در package.json قفل شده؛ نسخه‌ی 8 نوشتن شرطی را پشتیبانی نمی‌کند).
- پلن رایگان Netlify سقف دارد؛ قبل از فروش زیاد، شرایط فعلی را ببینید.

## ورود به پنل مدیر
- آدرس: `https://اسم-سایت.netlify.app/rv-admin-k9yrvqund5rutr8d7ujvpkrvwdpl/` (این آدرس را جایی منتشر نکن؛ در لینک‌های سایت هم نیست).
- ورود با «شماره‌ی مدیر» و «رمز مدیر». در کد فقط هش آن‌ها هست.
- اگر شماره یا رمز را فراموش کردی (و تا حالا رمز را از داخل پنل عوض نکرده‌ای): روی کامپیوترت `npm ci` بزن و `node tools/make-admin-cred.mjs 09xxxxxxxxx "رمز-جدید-قوی"` را اجرا کن؛ خروجی را در `netlify/lib/admin-cred.mjs` بگذار و دوباره Deploy کن.
- اگر قبلاً رمز را از داخل پنل عوض کرده‌ای، رمز تازه در Netlify Blobs (فروشگاه `rv-locks`، کلید `_admin`) ذخیره شده و فایل بالا را نادیده می‌گیرد؛ آن کلید را باید پاک کنی.
